Crop Overview & Cultivation Guide

Potatoes thrive in cool, porous soil. Soil moisture below 60% during tuber initiation causes irregular knobbing and reduced tuber count, while saturation (>85%) causes blackheart and soft rot (Erwinia).

Calibrated Sensor Parameters & Thresholds

  • Rhizosphere capacitive sensor depth 10–15cm inside bulking zone.
  • Automated pulse irrigation threshold: ON < 65%, OFF > 80%.
  • Stolon hooking and tuber enlargement cycle tracking.

    Connect Microcontroller Hardware

    PlantoPRO connects wirelessly via HC-02 Bluetooth (BLE 4.0 / HC-05/06 compatible) or via USB Serial cable. In absence of a hardware connection, live telemetry is held in standby.

    No Hardware Detected Connect wirelessly via Bluetooth HC-02 or plug in via USB COM port.
    1 Wire HC-02 6-pin module (STATE→D5, RXD→D3 via 1k/2k divider, TXD→D2, GND→GND, VCC→5V)
    2 Connect wirelessly via Web Bluetooth (HC-02 BLE) or pair in Windows (PIN 1234/0000) & select COM port
    3 Live microclimate & soil moisture telemetry will unlock immediately with 3 automated irrigation pumps

    HC-02 Bluetooth & Arduino Wiring Schematics

    6-Pin HC-02 (HC-05/06 compatible) • 4-Channel Relay (IN1, IN2, IN4) • DHT11 • Dual Soil Probes

    HC-02 6-Pin Bluetooth Module Pinout

    HC-02 Pin Function Arduino Pin Connection Details
    STATE Link Status Pin D5 Input: HIGH when paired/connected, LOW when searching
    RXD Serial RX Pin D3 (TX) 3.3V Logic: Use voltage divider (1kΩ from D3, 2kΩ to GND)
    TXD Serial TX Pin D2 (RX) Direct wire: 3.3V output safely detected as HIGH by Arduino
    GND Ground GND Common ground bus with sensors and relays
    VCC Power (5V) 5V Connect to Arduino 5V rail (onboard LDO drops to 3.3V)
    EN / KEY AT / Wake NC Leave unconnected for transparent data transmission

                Windows Bluetooth Pairing (Web Serial Bluetooth COM):
                
    Open Windows Settings → Bluetooth & devices → Add device → Bluetooth. Select "HC-02", "HC-05", or "BT05". Enter default PIN 1234 or 0000. Once paired, click "Connect Bluetooth COM / USB" in PlantoPRO and pick the standard Bluetooth serial port at 9600 Baud.
    
              
    
            
    
            
    
              
    2
    
              
    
                Web Bluetooth BLE Connection (Direct Chrome/Edge):
                
    Click "Connect Wireless Bluetooth (HC-02 BLE)" directly in the browser. Select your device from the browser popup. The browser connects via BLE GATT transparent UART (Service 0xFFE0 / Char 0xFFE1) with no OS pairing needed.
    
              
    
            
    
            
    
              
    3
    
              
    
                LED Indicators on HC-02:
                
    Fast Blink: Waiting for connection. Steady Lit or Double Blink: Successfully paired and actively transmitting telemetry.
    
              
    
            
    
            
    
              
    4
    
              
    
                Simultaneous USB & Bluetooth Streaming:
                
    Because the firmware uses SoftwareSerial on Pins 2 & 3 for Bluetooth and hardware Serial on Pins 0 & 1 for USB, you can upload sketches and monitor USB without disconnecting the HC-02!
